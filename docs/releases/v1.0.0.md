# Panopticon 1.0.0

[English](https://github.com/anonymmized/Panopticon/blob/v1.0.0/docs/releases/v1.0.0.md) | [Russian](https://github.com/anonymmized/Panopticon/blob/v1.0.0/docs/releases/v1.0.0.ru.md)

A free native Dock for macOS, with persistent app pins, independent spaces,
window selection and useful everyday widgets.

- Smooth slide-in and slide-out at all four screen edges, with reversible motion
  and support for macOS Reduce Motion.
- Hover over a running app to choose a window, including minimized windows.
  Window queries run off the main thread. Enable Accessibility explicitly to use them.
- App clicks deliver the normal reopen request, including to apps with no windows.
- Eight glass themes, magnification, launch bounce, app badges and configurable layouts.
- Clock, focus timer, calendar and Spotify / Apple Music widgets.
- Search, folder stacks, collections, website shortcuts and appearance profiles.
- English and Russian, light and dark appearances, and settings that apply immediately.
- System Dock import and optional replacement, with original settings restored on exit.

## Install

Download **Panopticon-1.0.0-universal.dmg**, open it and drag Panopticon to Applications.
Requires **macOS 13 or newer**; the same app supports **Apple Silicon and Intel**.
Quit the existing Panopticon before replacing it. Saved settings remain in place.

This build is **not notarized by Apple**. After attempting to open it, use
**System Settings > Privacy & Security > Open Anyway**, then confirm, if macOS asks.
The checksum file verifies the downloaded image against the published artifact.

## Known limits

- Mission Control displays the system Dock; Panopticon yields there to prevent overlap.
- Window selection lists application windows, not individual browser tabs or screenshots.
- Accessibility, calendar access and music control are optional and require explicit consent.
- No in-app updater is included. Download the latest release to update.
