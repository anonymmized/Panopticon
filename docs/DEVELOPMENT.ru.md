# Разработка

[Английский](DEVELOPMENT.md) | [Русский](DEVELOPMENT.ru.md)

Приложение использует режим языка Swift 5, требует macOS 13+ и не имеет внешних библиотек.
Панель реализована в AppKit, настройки, редакторы и поповеры — в SwiftUI. Сначала прочитай
[архитектуру](ARCHITECTURE.ru.md) и [правила участия](../AGENTS.ru.md).

Начинай задачи от актуальной `main` в отдельных ветках. До параллельных правок согласуй
общие поля модели, формат настроек и точки входа. Используй нативные меню, семантические
визуальные токены и общий сервис локализации.

## Обязательные локальные проверки

```sh
python3 scripts/check_localizations.py
python3 scripts/check_documentation.py
swift build -c release
.build/release/Panopticon --self-test
.build/release/Panopticon --panel-self-test
./build.sh
build/Panopticon.app/Contents/MacOS/Panopticon --self-test
build/Panopticon.app/Contents/MacOS/Panopticon --panel-self-test
codesign --verify --deep --strict build/Panopticon.app
git diff --check
```

Тестам панели нужен WindowServer. В Linux не запускай AppKit-тесты. Используй отдельные
UserDefaults и созданные для проверки файлы. Доступы к календарю, музыке и папкам
проверяются отдельно только по явному действию пользователя.

`--ui-review` открывает настоящие настройки с изолированными данными, без глобальных
клавиш, замены системного Dock и владения сессией. `--small-window` включает минимальный
размер окна. Проверяй оба языка и оформления, поиск, редакторы, знакомство, длинные строки
и обратную связь доступности.

`--render-review` сохраняет изолированные снимки настроек и панели в
`build/interface-review`. Это помогает проверять тексты и смену языка; нативная боковая
панель может сниматься не полностью, поэтому живой проход окна всё равно нужен.

## Проверка упаковки и восстановления

```sh
./scripts/test_install.sh
./scripts/make_dmg.sh --skip-build
./scripts/verify_distribution.sh build/Panopticon-*-arm64.dmg
```

Проверка установки использует временные папки и искусственную ошибку перемещения для
проверки отката. Верификатор сверяет манифесты, подписи, архитектуры, хеши и содержимое
смонтированного образа. Универсальная сборка описана в [дистрибуции](DISTRIBUTION.ru.md).

## Локальные команды

| Флаг | Действие |
|---|---|
| `--settings` | Открыть настройки при запуске |
| `--diagnostics` | Локальный отчёт без активации и запроса разрешений |
| `--visibility-state` | Запрос состояния панели без её показа |
| `--restore-system-dock` | Согласованное восстановление с текущим владельцем |
| `--ui-benchmark` | Изолированная проверка геометрии и рисования |

Не коммить сборки, кеши, установщики, ключи подписи и личные экспорты профилей.
Без явного указания владельца не выполняй push, публикацию и отправку на нотариализацию.
Локальная упаковка ничего не публикует.

## Изображения документации

Команда `.build/release/Panopticon --render-docs` на macOS обновляет восемь изображений
на русском и английском в `docs/assets`. Используются настоящие компоненты панели
и настроек с отдельными демонстрационными данными. Проверь каждое изображение перед
коммитом: личных событий, имён файлов, аккаунтов и внешних загрузок там быть не должно.
Типографика README использует обычную разметку GitHub; обложка содержит надпись,
системный шрифт и градиентное оформление.

## Локальные замеры и проверка сессии

`./scripts/run_platform_probe.sh 30 build/idle.json` измеряет видимую панель без
виджетов и подключений. `PROBE_SCENARIO=autohide` включает часы с секундами, незапущенный
фокус и автоскрытие. `SMOKE_LIFECYCLE=1 PROBE_LANGUAGE=en` дополнительно проверяет
подтверждение владельца и запуск второго экземпляра на английском; настройки в этом
режиме открываются, поэтому он не измеряет покой. Каждый запуск использует отдельные
идентификатор и настройки, отключает замену Dock и подключения, удаляет созданное
состояние при выходе. В отчётах указывается исходная сборка.

## Оформление установщика

DMG использует `resources/dmg/background.png` и сохранённый макет Finder с крупными
иконками приложения и Applications. Макет — исходный ресурс оформления, а не готовый
установщик. Фон можно обновить командой `swift scripts/render_dmg_background.swift`.
Обычной сборке нужны только сохранённые ресурсы; сторонние библиотеки упаковки не нужны.
После изменения макета проверь образ и его вид после нового подключения.
Имя тома остаётся Panopticon для стабильного разрешения ссылки на фон.

`ARCH=universal ./scripts/package_commit.sh HEAD build/release` упаковывает выбранный
локальный коммит во временной копии, записывает его в манифест и ничего не отправляет.
По умолчанию подпись ad-hoc; `NOTARIZE=1` требует явно указанного Developer ID.
