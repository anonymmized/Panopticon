# A0 — первая сборка и стабилизация

Исторический отчёт до объединения с FreeDock (0.4). Текущая общая база описана в [INTEGRATION.md](INTEGRATION.md).

Дата: 2026-10-14. Локальная ветка: `design-brainch`.

## Область проверки

По указанию владельца A0 из `AGENTS_PLAN.md` применяется к текущей версии
NewMacBar в `fashion_hab`. Внешний план описывает другую структуру FreeDock.
Переименование приложения и реализация отсутствующих функций не входят в A0.
Пуши, PR, изменение настроек репозитория на GitHub и слияние не выполнялись.

## Исправления

- Добавлен SwiftPM executable target, Swift language mode 5, macOS 13+,
  без зависимостей. Прямая сборка использует архитектуру текущего Mac вместо
  жёстко заданной arm64 и тот же языковой режим.
- Добавлен `build.sh [install]`: сборка, проверка ad-hoc подписи, установка
  в `/Applications`; `INSTALL_DIR` позволяет выбрать другой каталог.
  До замены установленная версия сохраняется в скрытой резервной папке.
  Новая версия копируется и проверяется до замены старой.
- Прозрачные поля панели теперь переключают `NSWindow.ignoresMouseEvents`.
  Одного `NSView.hitTest == nil` недостаточно для передачи события другому
  приложению. Геометрия включает основной прямоугольник и увеличенные иконки.
  Глобальный/локальный монитор движения обновляет состояние при пересечении
  границы; периодический тик и изменение геометрии также его обновляют.
- Иконки принимают первый клик без активации панели.
- При выходе удаляются мониторы событий и уведомлений, останавливается таймер.
- Фоновое чтение музыкального плеера предварительно проверяет Automation
  без запроса разрешения. Запрос допускается после нажатия на виджет.
- Добавлен независимый AppKit-тест панели с временными настройками.
- Добавлен `.github/workflows/build.yml`: release, регрессии, AppKit-тест,
  сборка и проверка `.app`, ZIP-артефакт. Выполнение в GitHub не проверялось:
  владелец запретил отправку изменений.

## Воспроизводимые проверки

```sh
set -o pipefail
swift build -c release 2>&1 | tee build.log
.build/release/NewMacBar --self-test
.build/release/NewMacBar --panel-self-test
./build.sh install
codesign --verify --deep --strict /Applications/NewMacBar.app
zsh -n build.sh scripts/build_app.sh
git diff --check
```

В ограниченной песочнице компилятору может потребоваться доступ к своему
кешу, а AppKit-тесту — к WindowServer. Локально эти команды выполнялись
с разрешённым доступом. Сообщение о несовместимости SDK в первой попытке
было следствием запрета записи `SwiftShims` в кеш; вне песочницы release
собирается без ошибок и предупреждений. `build.log` не включён в Git.

## Найденные проблемы и ограничения для слияния

| ID | Где | Описание | Статус |
|---|---|---|---|

A0 для текущего кода стабилизирована локально. Полный DoD внешнего плана
не следует отмечать выполненным до проверки функций объединённой версии,
внешнего drag-and-drop и зелёного удалённого CI.

## Общие файлы и контракт слияния

Изменены `main.swift` (жизненный цикл, обновление click-through, открытие
плеера по действию), `BarView.swift` (панель, первый клик, общий хит-тест),
`MusicController.swift` (разрешение перед фоновым AppleScript),
`RegressionTests.swift` (AppKit-тест), сборочные файлы и `.gitignore`.
Новых полей сохранённой модели нет; формат пользовательских настроек
и bundle identifier не менялись. При переносе в FreeDock сохранить
проверку разрешений и обновление `ignoresMouseEvents` по фактической
геометрии. Не переносить жёсткую архитектуру arm64 из старого build script.
