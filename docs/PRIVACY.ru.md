# Приватность и разрешения

[Английский](PRIVACY.md) | [Русский](PRIVACY.ru.md)

В Panopticon нет телеметрии, рекламы, платежей и обязательного аккаунта. Настройки,
пути, наборы, профили, выбранные календари и фокус-сессии остаются в локальном домене
настроек приложения.

| Доступ | Назначение | Когда запрашивается |
|---|---|---|
| Календари | Чтение событий аккаунтов macOS | Кнопка подключения |
| Automation для Spotify / Music | Чтение и управление выбранным плеером | Явное действие с плеером |
| Automation для Finder | Очистка системной Корзины | После подтверждения |
| Универсальный доступ | Необязательный выбор окон и бейджи Dock | Отдельная кнопка |

Остальные функции работают без этих подключений. Фоновый опрос и запуск не запрашивают
новые разрешения. Согласием и отзывом управляет macOS. События только читаются;
Panopticon не редактирует и не передаёт их.

Обложки Spotify загружаются по адресу, полученному от плеера. Иконки сайтов запрашиваются
напрямую с добавленных сайтов, без прокси. Сервер видит обычный запрос и сетевой адрес
соединения. Содержимое локальных папок не загружается в сеть.

Диагностику можно просмотреть до сохранения. Она не содержит личных путей, событий,
адресов сайтов, списка приложений и идентификаторов экранов. Автоматической отправки нет.
Экспорт профиля JSON может содержать личные пути и названия; не добавляй такие файлы
в публичные репозитории.

Перед заменой системного Dock сохраняется локальная копия его настроек. Она остаётся
до успешного восстановления. Обычный выход возвращает настройки. Список закреплённых
приложений системного Dock не очищается и не переписывается.

Тесты используют отдельные настройки и созданные для проверки файлы. Они не выдают
разрешений, не очищают настоящую Корзину и не меняют пользовательские документы.

## Список окон

При наведении на запущенное приложение запрашивается список его окон через
Универсальный доступ. Названия хранятся только в памяти до закрытия списка,
не записываются в настройки, диагностику или телеметрию. Окна других приложений
в этот момент не опрашиваются. Снимки экрана не делаются; разрешение на запись
экрана не запрашивается. Разрешение Универсального доступа запрашивается только
по нажатию кнопки подключения. Открытие списка само по себе его не запрашивает.
