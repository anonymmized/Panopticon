# Передача платформы и интерфейса NewMacBar

Ветка: `codex/platform-and-interface`, база: `main` / `53dd4a3` (объединённая 0.5).
Полный исходный план: [MASTER_PLAN.md](MASTER_PLAN.md).
Работа локальная: push, PR и публикация не выполняются.
Целевой артефакт этой ветки — разработческая 0.6.0, не финальный релиз 1.0.

## Разделение файлов

P01 выполнен механически, публичные существующие типы сохранены:

| Раньше | Теперь | Кто продолжает |
|---|---|---|
| main.swift | main.swift, AppDelegate.swift, SelfTests.swift | Codex: запуск и окна; Claude: модельные проверки |
| QuickLauncher.swift | GlobalShortcut.swift, AppCatalog.swift, LauncherView.swift | Claude: первые два; Codex: LauncherView |
| Actions.swift | QuickLink.swift, Profile.swift, ProfileActions.swift, ActionRouter.swift | Claude: DTO/модельные команды; Codex: открытие ресурсов |
| DockIntegration.swift | AppCollection.swift, FocusTimer.swift, DockIntegration.swift | Claude: первые два; Codex: системный Dock |
| BarView.swift (окно) | DockWindowController.swift, PanelPlacement.swift | Codex |
| SettingsView.swift | SettingsView, AppearanceSettings, WidgetSettings, LibrarySettings, BehaviorSettings, SystemSettingsView | Codex |

`BarView`, `BarDrawing` и `BarMenus` делят внутреннюю геометрию только внутри
модуля интерфейса; сервисы не должны мутировать эти поля напрямую.

`BarModel` остаётся единственным владельцем доменного состояния. `UIStateStore`
содержит только оформление окон, выбранный раздел и завершение знакомства.
Не копировать содержимое пространств или профилей в представления.

## Claude: точки интеграции без переделки экранов

1. **C01/C02.** `PanelActions.swift` — единственное временное место новых команд переноса
   ссылок/коллекций и проверки конфликтов. Перенести мутации в Command API; сохранить
   контракты результата `Bool`/сообщения для drag. `SpacesSettingsView`, `ProfileRow`,
   `LibrarySettings` держат только последнюю UI-отмену: заменить её общим UndoState.
   В SystemSettingsView добавить полные export/import/reset/restore с preview и
   состоянием записи, когда SettingsStore действительно существует. Профиль уже
   экспортируется отдельно. Не выдавать профиль за полную резервную копию.
2. **C03.** `CalendarPopoverView` использует `events`, `authorized`, `enabled/loading`,
   `message`, `showMonth`, `connect`. `AppDelegate` передаёт предпочтения и освежает
   статус по возврату в приложение, не запрашивая доступ. Сохранять разницу между
   источником событий macOS и приложением назначения.
3. **C04.** `MusicPopoverView` использует текущий snapshot, Connect запрашивает доступ
   явно. `FocusPopoverView` использует sessionDuration/remaining/progress.
   Закрытый или выключенный виджет не должен возобновлять фоновые запросы.
4. **C05.** `LauncherResult` — представление результата с ID и действиями. Заменить
   построение `results` в LauncherView выдачей SearchEngine. ID обязаны быть
   стабильны; Command+Enter без pin-действия ничего не запускает.
5. **C06.** `FolderPresentationLoader` — временный UI-адаптер, не новая постоянная
   файловая служба. Вставить FolderState; сохранить loading/error/empty/limit,
   sort/list/query и ID-выбор. Временно используются системные символы файлов:
   асинхронные thumbnails/icons принадлежат IconState. Большие/сетевые папки не
   читать на main thread. Подключить watch/paging после готовности API.
6. **C07.** Логика горячих клавиш механически вынесена, поведение сохранено.
   Объединить GlobalShortcut и HotKeys, передать всем строкам ShortcutStatus;
   сейчас диагностика достоверно знает регистрацию только launcher.
7. **Точечный фикс Model.swift.** У `secondaryWidget.didSet` условие должно
   исключать `"none"`: иначе оба выключенных виджета вызывали бесконечное
   присваивание `none` и переполнение стека при старте/выключении. Это одна
   необходимая строка вне механического P01; сохранить её при слиянии C02/C04.
   Регрессия проверяет сохранение и перезапуск с обоими выключенными виджетами.
8. **C08/C09.** Новые AppKit-тесты в PlatformTests; wiring в SelfTests/RegressionTests.
   `KeyboardCommands` не перехватывает события других окон и IME composition.
   Добавить строки новых UI-файлов в каталог RU/EN. Не переводить идентификаторы,
   URL схемы, plist keys или значения перечислений.

Служебные ключи `platform.activeSession`, `systemDockBackup` исключать из импорта,
сброса и переносимой пользовательской резервной копии. UI-ключи `ui.appearance`,
`ui.settingsSection`, `ui.onboardingCompleted` могут быть отдельной секцией новой
схемы; обязательна обратная совместимость текущих ключей при первой миграции.

## Gemini: точки дизайна

Токены: DesignSystem.swift; панель AppKit: BarView.swift/BarDrawing.swift/BarMenus.swift/Theme.swift;
карточки: StudioCard; варианты: OptionTile; empty state: EmptyState;
внутренняя галерея: «О программе → Компоненты интерфейса».
Оконная тема независима от темы панели. Системные варианты доступности обязательны.

Нужны утверждённые размеры, цвета, типографика, сетка, overflow, фокус/hover/pressed,
вертикальные варианты, длинные тексты, состояния доступа/ошибок и макет DMG.
Для native SF Symbols отдавать имя символа и размер, для графики — экспорт assets
с лицензией/назначением. Код не связывать с макетными названиями сервисов.

## Локальная проверка

```sh
swift build -c release
.build/release/NewMacBar --self-test
.build/release/NewMacBar --panel-self-test
./build.sh
build/NewMacBar.app/Contents/MacOS/NewMacBar --ui-review
build/NewMacBar.app/Contents/MacOS/NewMacBar --ui-benchmark
./scripts/run_platform_probe.sh 300 build/idle-probe.json
./scripts/test_install.sh
./scripts/make_dmg.sh --skip-build
./scripts/verify_distribution.sh build/NewMacBar-0.6.0-arm64.dmg
git diff --check
```

`--ui-review` открывает настройки с отдельной случайной UserDefaults suite и
подменённым Dock executor; реальные настройки панели не трогает. Не нажимать
Connect/Login во время автоматической приёмки: это реальные пользовательские
действия. Выход закрытием окна удаляет тестовую suite.

Автопроверки не удаляют реальные файлы, не очищают Корзину, не запрашивают доступ,
не регистрируют Login Item и не изменяют `com.apple.dock`.

## Ручной UI-проход на контрольном Mac

Через изолированный `--ui-review` проверены: поиск раздела «размер иконки»,
создание пространства через Return, подтверждение удаления и доступная отмена,
переключение светлой темы, повторное открытие всех четырёх шагов знакомства и
завершение без подключения разрешений. Обнаружен и исправлен пустой лист
диагностики: отчёт теперь передаётся immutable sheet item. Повторный проход
показал заполненный JSON и доступный экспорт. Это не полный проход VoiceOver.

## Проверки полного запуска

Дополнительный smoke использует реальный AppDelegate с отдельным bundle ID,
одноразовыми preferences и выключенной заменой Dock. Проверены подтверждение
`--restore-system-dock` от работающего владельца, активация первого экземпляра
при попытке второго запуска и удаление session marker при обычном выходе.
Launch Services недостаточно для поиска accessory-процесса, запущенного напрямую:
поэтому добавлена kernel flock, освобождаемая даже при аварии. `session.lock` в
Application Support — служебный файл, не часть переносимой конфигурации C01.

```sh
SMOKE_LIFECYCLE=1 ./scripts/run_platform_probe.sh 30 build/lifecycle-probe.json
```

В редакторе коллекций доступны значок, порядок самих коллекций и удаление
недоступных путей. Обновление профиля с совпадающим именем требует подтверждения
и имеет локальную отмену. Проверка настроек в минимальном окне 760×540 показала
доступную прокрутку; ввод размера 999 ограничился 60, выключение виджетов успешно.

## Последние исправления по ручной проверке

- `ApplicationMenus` добавляет нативные команды undo/cut/copy/paste/select all:
  menu направляет их по responder chain активному полю. UI Review использует тот
  же presenter поиска и отдельную suite без запуска системного жизненного цикла.
- Проверены вставка русского запроса, Enter для действия, Command+Enter без pin
  (не запускает действие), Command+Enter для приложения (Safari появился среди
  четырёх закреплённых), Escape и повторное открытие.
- В `AppCatalog` — небольшой дополнительный фикс: Safari определяется через
  NSWorkspace, поскольку на текущей macOS находится вне обходившихся корней;
  алиасы нормализуются до дедупликации. Сохранить этот случай при реализации C05.
- Панель учитывает safe area камеры при скрытой строке меню; геометрический тест
  не заменяет проверку реального notch/внешних мониторов.
- Новый QA bundle ID не был разрешён инструментом Computer Use. Для его жизни
  использованы CLI smoke; ручной UI-проход выполнен в разрешённом `--ui-review`.

Финальный idle прогон: 300.998 s, CPU 0.0283% одного ядра, physical footprint
13 878 088 bytes. Методика и ограничения — [PERFORMANCE.md](PERFORMANCE.md).
Команды выпуска и ограничения подписи — [DISTRIBUTION.md](DISTRIBUTION.md).

Кнопки виджетов AppKit отдают в AX динамические значения часов, таймера, плеера и календаря; отдельная проверка подтверждает значение часов. Это не заменяет ручную приёмку VoiceOver.

Локальная отмена коллекций и применения профиля ограничена исходным пространством; при смене набора устаревшая отмена сбрасывается, чтобы не применить снимок к другому набору. Полный межконтекстный журнал остаётся C02.

Для двух активных виджетов есть переключатель редактируемого источника: параметры часов/таймера/календаря доступны и для второго виджета без перестановки основного. Оформление остаётся общим в текущем контракте BarModel.
