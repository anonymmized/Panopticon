# Руководство пользователя

[Английский](USAGE.md) | [Русский](USAGE.ru.md)

## Установка и обновление

Скачай DMG из [последнего релиза](https://github.com/anonymmized/Panopticon/releases/latest),
открой его и перетащи Panopticon в Applications. Нужна macOS 13+; одна сборка подходит
для Apple Silicon и Intel. При обновлении сначала заверши запущенную копию.
Настройки сохранятся. Сборка из исходников для обычной установки не нужна.
Если первый запуск блокируется, после попытки открытия выбери «Всё равно открыть»
в «Системные настройки → Конфиденциальность и безопасность» и подтверди действие.
Сборка не нотариализована Apple. Встроенного автообновления нет.

## Выбор открытых окон

Задержи курсор на иконке запущенного приложения примерно на полсекунды. Список покажет
до 30 доступных окон; прокрути его, если окон много. Нажатие переключает на выбранное
окно и восстанавливает его, если оно свёрнуто. Список также доступен через правый клик
→ «Окна приложения…». Наведение не забирает клавиатурный фокус.

Включи Универсальный доступ отдельной кнопкой, если он ещё не разрешён.
Разрешение можно отозвать в настройках macOS. Выключить выбор окон можно
в «Поведение и экраны → Окна при наведении». Названия считываются только для выбранного
приложения; запись экрана не нужна. Отдельные вкладки браузера остаются внутри браузера.
Если окно закрылось или приложение не ответило, обнови список либо открой приложение.

## Приложения и пространства

Открой настройки из строки меню или контекстного меню панели. Импортируй приложения
из Dock macOS либо добавь их самостоятельно. Закреплённые иконки остаются после закрытия.
Временные запущенные приложения исчезают при выходе; пункт «Оставить в Dock» закрепляет
их. Снятие закрепления удаляет только ярлык, а не приложение на диске.

Перетаскивай иконки для изменения порядка. Перенос на символ другого пространства
перемещает элемент в него. У каждого пространства свои приложения, коллекции, папки
и сайты. Оформление и подключённые календари общие. Автоматическое переключение
по рабочему столу работает при доступности его номера; ручное доступно всегда.

## Видимость и экраны

В разделе «Поведение и экраны» выбери край и монитор. Следование за курсором переносит
панель между экранами. При отключении выбранного монитора используется доступный экран,
а сохранённый выбор остаётся для повторного подключения.

Автоскрытие начинает работу со скрытой панелью. Короткое наведение к выбранному краю
показывает её, уход курсора — скрывает с небольшой задержкой. Перетаскивание файла
к краю тоже может показать панель для размещения. Настройки и посторонние клики
не вызывают скрытую панель. Явные команды меню и клавиатуры могут её показать.

«Полные анимации» включает волну увеличения и прыжок запуска. «Как в macOS» учитывает
системное уменьшение движения. Уменьшенный режим сохраняет обратную связь без увеличения
и прыжков. Снижение прозрачности включает сплошные поверхности, повышение контраста —
более заметные границы.

## Виджеты

Доступны два разных виджета одновременно. На вертикальной панели они компактные.
Фокус-сессия сохраняется при перезапуске. Изменение следующей длительности не сбрасывает
сессию на паузе; для явного начала заново есть «Сбросить».

Выбери Spotify, Apple Music или автоматический источник. Подключение управления
выполняется по нажатию. Воспроизведение браузера не поддерживается. Названия треков
и обложки берутся из плеера и не переводятся.

Нажатие календаря может открывать любое приложение или сайт http/https. Доступ
к событиям подключается отдельно через календари macOS. Пустой сохранённый список
означает все календари; «Снять выбор» явно выключает все. Выбор стороннего приложения
не подключает аккаунт этого сервиса.

## Папки, файлы и Корзина

Перетащи папку на свободную часть панели, чтобы создать стопку. В ней доступны поиск,
сетка, список, обновление и сортировка. Показывается до 500 элементов; весь каталог
можно открыть в Finder. Для перемещённой или недоступной папки есть повторная попытка
и переход в Finder.

Документ можно перетащить на иконку приложения для открытия в нём. Удаление ярлыка
не затрагивает исходный файл. Реальный файл из Finder, перенесённый на Корзину,
попадает в системную Корзину. Очистка всегда требует подтверждения.

## Профили, поиск и язык

Профиль хранит оформление и снимок текущего набора. Его применение сохраняет внешние
календарные подключения. Импорт и экспорт выполняются через локальный JSON. Перед
применением импорта можно проверить состав; у изменений набора и профиля есть отмена.

Поиск поддерживает сокращения и исправление раскладки. Стрелки выбирают результат,
Return открывает, Command-Return закрепляет приложение, Escape закрывает поиск.
Глобальное сочетание настраивается; при конфликте остаётся пункт строки меню.

Язык выбирается внизу боковой панели: русский, английский или системный.
Переключение немедленное. Названия пространств, профилей, путей, треков и событий
остаются такими, какими были введены.

## Клавиши

| Сочетание | Действие |
|---|---|
| Control-Option-Пробел | Поиск; сочетание настраивается |
| Control-Option-1…9 | Выбор пространства |
| Control-Option-Влево / Вправо | Предыдущее / следующее пространство |
| Control-Option-D | Показать / скрыть панель |
| Command-запятая | Настройки активного приложения |

## Восстановление

Выбери «Вернуть системный Dock» в строке меню или разделе «Система и восстановление».
После прерывания сессии копия настроек сохраняется: можно восстановить Dock или
продолжить. Команда `Panopticon --restore-system-dock` согласует действие с работающим
экземпляром и не запускает конкурирующую запись.

Для полного выезда панели выбери **Внешний вид > Движение > Полные анимации**.
Режим «Как в macOS» учитывает системное уменьшение движения; уменьшенный режим
использует короткое затухание. Приложения получают обычную команду повторного открытия
даже когда уже запущены и могут восстановить или создать окно, если открытых окон нет.

После обновления сборки с подписью ad-hoc macOS может попросить снова одобрить
Универсальный доступ или другие подключения. Настройки самой панели сохраняются.
