# Объединённая исходная база 0.5.0

Panopticon (ранее NewMacBar) + FreeDock (`origin/freedock`, `d914ef2`), 2026-10-14.
Одна программа, один bundle identifier `app.newmacbar.desktop`, один executable
`Panopticon`. В `main` нет второго параллельного приложения и дублирующей модели.

## Что объединено

Из текущего Panopticon сохранены AppKit-панель, раздвигающее иконки увеличение,
редактор точных параметров, профили, коллекции, два настраиваемых виджета,
маршрутизация в любой календарь или сайт, выбор EventKit-календарей,
плеер с перемоткой/громкостью, устойчивый таймер, восстановление системного Dock,
поиск с неверной раскладкой, singleton и исправления A0.

Из FreeDock перенесены и адаптированы пространства, уникальные привязки к
рабочим столам, прокрутка и Carbon-хоткеи, четыре края и следование за курсором,
восемь тем, стопки папок, файлы/URL, корзина, AX-бейджи и список окон.
`Desktops.swift`, `Accessibility.swift`, `HotKeys.swift`, `Theme.swift` и
`MenuAction.swift` происходят из этой ветки; остальное встроено в текущую
архитектуру с сохранением прежней модели настроек.

Git-истории были независимыми. Merge сохраняет обе истории, а дерево исходников
составлено из выбранных и адаптированных функций. Одноимённые Model.swift,
AppDelegate и сервисы из двух проектов не запускаются параллельно.

## Данные

Существующие UserDefaults `app.newmacbar.desktop` читаются без сброса.
В первое пространство «Главное» переносятся закреплённые приложения,
коллекции и ярлыки. Создаются пустые «Работа» и «Отдых». Общие виджеты,
календарь и профили сохраняются. Пространства хранятся в ключе `spaces`,
выбранный ID — `selectedSpaceID`.

FreeDock `~/Library/Application Support/FreeDock/config.json` импортируется
по кнопке в разделе «Пространства». Импорт добавляет наборы к существующим,
а оформление переносится только с соответствующей галочкой. Исходный файл
не изменяется. Неподдерживаемые URL отбрасываются; размеры, количество
пространств и значения настроек ограничены. У профилей новые поля optional.

| Model, Actions, SettingsRules | Настройки, профили, действия и ограничения |
| Spaces, FreeDockImport | Наборы и совместимость с исходной веткой |

## Проверка и пределы базы

`--self-test` проверяет сохранение старых настроек, профили, коллекции,
поиск, календарные границы, музыку, таймер, восстановление Dock, пространства,
уникальность привязок, перемещение между наборами и импорт FreeDock.
`--panel-self-test` проверяет первый клик, прозрачные поля, возврат
взаимодействия, отсутствие keyboard focus и геометрию всех четырёх краёв.

Рабочие столы определяются через необязательные приватные символы SkyLight.
Если macOS меняет API, остаётся ручное переключение. Приложение не перемещает
окна между рабочими столами. Mission Control сам показывает стандартный Dock;
наша панель использует transient. Полное отключение Dock не обещается.
Бейджи и окна требуют необязательного Универсального доступа, события —
доступа к календарям, музыка — Automation. Эти разрешения не выдаются тестами.
Стопка папки показывает до 500 нескрытых элементов. В вертикальном баре
виджеты автоматически компактные. Максимум 30 пространств, размер иконок
28–60 pt. Установщик по умолчанию соответствует архитектуре машины сборки.

Удалённый GitHub Actions не запускался; исходники и DMG не публиковались.
