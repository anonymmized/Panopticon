# Проверка общей базы 0.5.0

2026-10-14, macOS 26.6.2 (25G83), Apple Silicon arm64.

## Пройдено локально

- `swift build -c release`: без ошибок и предупреждений.
- `--self-test`: прежние регрессии и новые интеграционные проверки.
- `--panel-self-test`: геометрия четырёх краёв, первый клик, прозрачные поля,
  отсутствие keyboard focus, нативные меню и AppKit drag-and-drop.
- AppKit pasteboard: приложение, папка, веб-ссылка, отклонение неверного
  `.app`, удаление только закреплённого ярлыка при внутреннем drop в корзину.
- Установка в `/Applications/NewMacBar.app`, проверка ad-hoc подписи,
  запуск и ровно один рабочий процесс.
- Интерфейс: главное/рабочее пространство, возврат к главному,
  выбор через ⌃⌥1/2, переход по ⌃⌥→, скрытие/возврат по ⌃⌥D.
- Поиск по ⌃⌥Пробел: ввод названия пространства, выбор Enter.
- Левый вертикальный бар: иконки остаются вертикально ориентированными,
  календарная дата при размере иконок около 30 pt читается после исправления.
- Новые настройки пространств, выбор края, работа автоскрытия.
- Возврат исходного нижнего края и исходного автоскрытия после проверки.
- Семантическое сравнение прежних настроек до/после: отличий нет для
  приложений, размера/интервалов, темы, оформления, профилей, коллекций,
  ярлыков, виджетов, плеера, таймера и календарных связей. Добавлены 3 пространства.
- `zsh -n`, `plutil -lint`, `git diff --check`.
- `NewMacBar-0.5.0-arm64.dmg`: `hdiutil verify` и SHA-256 прошли.
  Образ смонтирован read-only, подпись приложения проверена, `--self-test`
  выполнен из приложения на образе; образ отключён после проверки.

## Что требует отдельной проверки

- Реальная машина с macOS 13, Intel и несколько подключённых мониторов.
- Живые Spotify/Apple Music, календари и AX-окна/бейджи с разрешениями
  пользователя. Новые доступы в этой проверке не выдавались.
- Полная ручная проверка внешнего Finder drag-and-drop на реальных данных;
  обработчики проверены через AppKit pasteboard без изменения пользовательских файлов.
- Реальное удаление файлов и очистка Корзины не выполнялись.
- Gatekeeper на чистом чужом Mac, Developer ID и нотариализация не проверены.
- Удалённый GitHub Actions подготовлен, но не запускался: push и публикация
  запрещены владельцем на этом этапе.

Это исходная база для последующих задач, без заявления о готовности релиза 1.0.
