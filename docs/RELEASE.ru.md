# Готовность Panopticon 1.0 к выпуску

[Английский](RELEASE.md) | [Русский](RELEASE.ru.md)

Версия: **1.0.0**, сборка **10**. Канал: **кандидат на выпуск**.
Локальные проверки не публикуют релиз и не отправляют файлы на GitHub.

## Приёмка

| Область | Локальная проверка |
|---|---|
| Исходники | Release-сборка и изолированные тесты модели и панели |
| Языки | Совпадение каталогов, подстановки, формы чисел и английская основная документация |
| Сохранение | Закрепления с отключённых дисков переживают профиль, отмену удаления и перезапуск; пространства и профили |
| Фоновые задачи | Отменённое чтение папки не публикует ответ; длительности таймера нормализуются |
| Взаимодействие | Четыре края, переполнение, прозрачные поля, нативные меню, пружины и правила показа |
| Упаковка | Полные ресурсы, постоянный идентификатор, universal, строгая подпись и контрольные суммы |
| Установка | Проверенная копия, откат замены и сохранение оригинала при сбое самого отката |
| Документация | Настоящие компоненты с демонстрационными данными; отдельные русские и английские руководства |

Выполни `./scripts/check_release.sh`, собери `ARCH=universal ./build.sh`, затем запусти
`./scripts/test_install.sh`, создай образ и проверь его через
`./scripts/verify_distribution.sh`. Фактические результаты отражаются в [проверке](VALIDATION.ru.md).
Успешная команда не заменяет отдельные проверки с действиями пользователя ниже.

## Перед публичным распространением

- Проверь кандидата на поддерживаемых Mac и мониторах. Короткие автоматические тесты
  не подтверждают многодневную стабильность.
- Проверь календарь, плеер, Универсальный доступ и автозапуск явными действиями
  пользователя. Автоматические тесты не запрашивают эти разрешения.
- Подтверди подпись и нотариализацию для выбранного способа распространения. Локальная
  ad-hoc подпись не означает нотариализацию Apple. На текущем Mac не настроена подпись
  Developer ID; Apple Development — другой тип сертификата.
- Укажи поведение Mission Control в примечаниях: обзор показывает системный Dock и
  скрывает Panopticon. Полная замена внутри этого режима не реализована.
- Публикуй проверенный коммит и соответствующие DMG, манифест и SHA-256 только после
  отдельного указания владельца. Эта работа не публикует тег релиза.

## Изменения кандидата

- Сохраняются закрепления с отключённых дисков при применении профиля и отмене удаления.
- Отмена доходит до чтения папки и освобождает индикатор загрузки.
- Восстановленное время ограничивается длительностью сессии, некорректные числа отклоняются.
- Новый таймер и приостановленная сессия различаются в подписях и действиях.
- Числовые поля и временные статусы следуют выбранному языку интерфейса.
- Устаревшие иконки удаляются из кеша при изменении содержимого панели.
- Ресурсы проверяются до установки, оригиналы сохраняются при сбое отката.
- Документация получила иллюстрации, отдельные языковые версии и воспроизводимые примеры.

Сборка и подпись: [распространение](DISTRIBUTION.ru.md). Работа каждый день: [руководство](USAGE.ru.md).
