## Panopticon 1.0.0

- Smooth slide-in and slide-out at four edges, including uninterrupted reversal.
- Running-app window selection on hover and through the native context menu.
- Normal app reopen requests when an app is running with all windows closed.
- Background window queries, stale-result rejection and explicit Accessibility connection.
- Persistent app pins, spaces, collections, folder stacks and two configurable widgets.
- Eight glass themes, icon magnification, launch bounce and reduced motion.
- English and Russian interface, localized numbers/status and readable compact settings.
- Offline pin retention, removal undo, cancellable folder reads and persistent focus sessions.
- Universal DMG, checksums and installation/rollback verification.
- Illustrated guides, latest-release download links and a custom Homebrew tap generator.

This build is not notarized by Apple. Mission Control uses the system Dock.
Window selection does not list individual browser tabs. [Release notes](docs/releases/v1.0.0.md).
