# Panopticon

[Английский](README.md) | [Русский](README.ru.md)

Бесплатная панель для macOS 13 и новее. Закрепляй приложения, переключай пространства,
добавляй полезные виджеты и настраивай оформление рабочего стола. Swift, AppKit и SwiftUI,
без подписок, телеметрии и сторонних библиотек.

## Каждый день

- Закреплённые приложения остаются после закрытия. В меню запущенного приложения
  выбери «Оставить в Dock» или используй «Добавить из Dock macOS» в настройках.
- У пространств независимые приложения, коллекции, папки и сайты.
- Доступны четыре края экрана, несколько мониторов, автоскрытие, увеличение
  при наведении и анимация запуска.
- Часы, календарь, музыка и фокус работают в компактном или подробном виде.
- Приложение или сайт для открытия календаря выбирается отдельно. Источник событий —
  аккаунты календарей, подключённые к macOS.
- Поиск находит приложения, пространства, ярлыки, профили и действия.
- Настройки и поповеры поддерживают системное, светлое и тёмное оформление.
  Русский, английский и системный язык переключаются без перезапуска.

## Сборка и установка

Нужны macOS 13+ и Xcode либо Command Line Tools со Swift 5.9+.

```sh
swift build -c release
./build.sh
open build/Panopticon.app
```

Перед обновлением закрой установленное приложение:

```sh
./build.sh install
open /Applications/Panopticon.app
```

Установщик проверяет подпись и сохраняет ZIP-копию установленного приложения.
Идентичность приложения, настройки и разрешения сохраняются.
Другой каталог задаётся через `INSTALL_DIR="$HOME/Applications"`.

Универсальная сборка и локальный образ:

```sh
ARCH=universal ./build.sh
./scripts/make_dmg.sh --skip-build
./scripts/verify_distribution.sh build/Panopticon-*-universal.dmg
```

Без явно заданного Developer ID используется локальная ad-hoc подпись.
Подробности — в [документе о сборке](docs/DISTRIBUTION.ru.md).

## Замена Dock

Осознанно включи «Заменить системный Dock» в настройках. Panopticon импортирует
закреплённые приложения, сохраняет системные настройки Dock и возвращает их при выходе.
Восстановление также доступно из строки меню и настроек.

При автоскрытии панель появляется после короткого наведения к выбранному краю.
Обычные клики, активация приложений и фоновые обновления не вызывают панель.

Mission Control управляется macOS. Panopticon не перекрывает там системный Dock
и не обещает полной замены системной панели в этом режиме.

## Быстрая проверка

```sh
python3 scripts/check_localizations.py
python3 scripts/check_documentation.py
swift build -c release
.build/release/Panopticon --self-test
.build/release/Panopticon --panel-self-test
./build.sh
codesign --verify --deep --strict build/Panopticon.app
git diff --check
```

Тесты используют отдельные настройки, не запрашивают разрешений, не очищают Корзину
и не меняют реальные документы. Тестам панели нужен macOS WindowServer.
