# Panopticon

[English](README.md) · [Русский](README.ru.md)

Бесплатная панель для macOS 13+ на Swift, AppKit и SwiftUI, ранее называвшаяся
NewMacBar. Общая исходная база объединяет Panopticon и FreeDock. Без подписки, пробного периода,
телеметрии и сторонних библиотек.

С этой версии дальнейшая разработка начинается от `main`; задачи выполняются
в отдельных ветках. Устройство объединения описано в [INTEGRATION.md](docs/INTEGRATION.md),
правила работы — в [AGENTS.md](AGENTS.md), изменения — в [CHANGELOG.md](CHANGELOG.md).

## Возможности

- Стеклянная панель у нижнего, верхнего, левого или правого края; размер иконок,
  интервалы, скругление, прозрачность, увеличение и подписи настраиваются.
- 8 тем: Стекло, Тёмная, Светлая, Aurora, Electric, Sunset, Graphite, Frost.
- Пространства с независимыми приложениями, коллекциями, папками и сайтами.
  Переключение кликом, прокруткой, клавишами, из меню или поиска.
- Привязка пространства к номеру рабочего стола macOS и перенос панели
  на монитор с курсором. При недоступности системного API остаётся ручной выбор.
- Закреплённые и запущенные приложения, индикатор активного приложения,
  перетаскивание для порядка и переноса между пространствами.
- Файл можно открыть в приложении, перетащив на его иконку. Папки, файлы
  и сайты можно добавить через настройки или перетаскиванием.
- Папки открываются стопкой с сеткой, поиском и переходом в Finder.
  Сайты получают иконку непосредственно с самого сайта.
- Корзина: закреплённая иконка убирается из набора, внешний файл из Finder
  отправляется в системную Корзину. Очистка запрашивает подтверждение.
- Нативное меню приложения: список окон, скрытие, завершение,
  закрепление и перемещение в другое пространство. Список окон и бейджи
  требуют необязательного Универсального доступа.
- До двух виджетов: часы, календарь, музыка или таймер. Компактный и подробный
  вид, цвет и насыщенность; на вертикальной панели используются компактные виджеты.
- Музыка Spotify / Apple Music: обложка, управление, перемотка и громкость.
- Календарь месяца, события выбранных календарей macOS. По нажатию можно
  открыть выбранное пользователем приложение, Google Calendar или другой сайт.
- Таймер фокуса 5–90 минут сохраняет сессию при перезапуске.
- Профили оформления и текущего набора: сохранение, обновление,
  переименование, экспорт и импорт JSON.
- Поиск приложений, пространств, ярлыков, профилей и действий. Поддерживает
  сокращения и ошибочную русскую/английскую раскладку.
- Автоскрытие, выбор экрана и автозапуск через системный ServiceManagement.
- Замена стандартного Dock с резервной копией и восстановлением его настроек.

## Сборка и установка

Нужны macOS 13 или новее и Command Line Tools / Xcode с Swift 5.9+.

```sh
xcode-select --install   # если инструменты ещё не установлены
./build.sh
open build/Panopticon.app
```

Для установки в «Программы»:

```sh
./build.sh install
open /Applications/Panopticon.app
```

Скрипт сначала собирает и проверяет ad-hoc подпись, затем заменяет приложение.
Перед установкой закрой предыдущую версию. Предыдущая установленная версия
сохраняется в скрытой резервной папке; прежний NewMacBar.app в каталоге установки
также переносится в резервную копию при переименовании.
Другой каталог можно задать: `INSTALL_DIR="$HOME/Applications" ./build.sh install`.
Сборка соответствует архитектуре текущего Mac (arm64 или x86_64).

Локальный установщик и контрольная сумма:

```sh
./scripts/make_dmg.sh
# build/Panopticon-<версия>-<архитектура>.dmg
# build/Panopticon-<версия>-<архитектура>.dmg.sha256
```

DMG содержит приложение и ссылку на Applications. Developer ID и нотариализация
Apple в этой исходной базе не настроены. Сборка из исходников доступна без них.

## Проверки

```sh
swift build -c release
.build/release/Panopticon --self-test
.build/release/Panopticon --panel-self-test
./build.sh
codesign --verify --deep --strict build/Panopticon.app
git diff --check
```

`--self-test` использует отдельные UserDefaults и проверяет модель, перенос
старых настроек, пространства, профили, импорт, геометрию, календарные границы,
поиск, музыкальные данные, таймер и восстановление Dock.
`--panel-self-test` требует WindowServer и проверяет прозрачные поля,
первый клик, фокус, меню и четыре положения панели.

GitHub Actions повторяет сборку и тесты, создаёт ZIP и DMG. Запуск
на GitHub происходит только после отправки исходников владельцем;
локальная подготовка базы сама ничего не публикует.

## Язык интерфейса

Внизу боковой панели настроек выбери **Язык интерфейса → Как в системе / English / Русский**.
Настройки, поиск, меню панели и виджеты переключаются сразу, без перезапуска.
В системном режиме выбирается первый поддерживаемый язык в настройках macOS;
если подходящего нет, используется английский. Названия месяцев и дней недели
следуют выбранному языку.

Имена пространств, профилей, приложений, файлов и событий остаются прежними.
Системные диалоги и ошибки macOS могут использовать язык системы. Описания
запрашиваемых разрешений включены в приложение на русском и английском.
Язык интерфейса не входит в профили оформления и не меняется вместе с пространством.

## Клавиши

| Клавиши | Действие |
|---|---|
| ⌃⌥Пробел | Открыть / закрыть быстрый поиск; сочетание можно изменить |
| ⌃⌥1 … ⌃⌥9 | Выбрать пространство по порядку |
| ⌃⌥← / ⌃⌥→ | Предыдущее / следующее пространство |
| ⌃⌥D | Показать / скрыть панель |
| ↑ / ↓, Return, Escape | Выбор, открытие и закрытие поиска |
| ⌘Return в поиске | Закрепить выбранное приложение |
| ⌘, | Настройки, когда приложение активно |

Системные или сторонние сочетания могут быть заняты; для поиска остаётся
пункт в строке меню, для пространств — переключатель и меню.

## Настройки и перенос данных

Технический bundle ID сохранён от NewMacBar, чтобы не потерять данные и разрешения.
Не запускай старое и переименованное приложение одновременно: у них общая идентичность.
Настройки Panopticon хранятся в UserDefaults домена `app.newmacbar.desktop`.
Обновление сохраняет прежние приложения, профили, календарные связи и виджеты.
Названия начальных наборов зависят от выбранного языка: «Главное», «Работа»,
«Отдых» или Home, Work, Leisure. Два последних создаются пустыми.

В «Пространства → Настройки из FreeDock» можно импортировать старый
`~/Library/Application Support/FreeDock/config.json`. Это добавляет наборы
к существующим. Галочка отдельно разрешает перенести оформление и виджеты.
Исходный JSON не меняется. Выбор стороннего приложения календаря задаёт
приложение для открытия; события читаются отдельно из аккаунтов календаря macOS.

Прозрачные поля окна панели пропускают клики к другим окнам.
В Mission Control стандартный Dock показывается самой macOS; наша панель
скрывается для обзора. Полного отключения стандартного Dock приложение не обещает.
При обычном выходе исходные настройки Dock восстанавливаются; после сбоя
используй «Поведение → Вернуть системный Dock».

## Разрешения и данные

| Разрешение | Назначение |
|---|---|
| Календари | Чтение событий; запрашивается кнопкой подключения |
| Автоматизация → Spotify / Music | Управление и чтение музыкального плеера после действия пользователя |
| Автоматизация → Finder | Очистка Корзины после подтверждения |
| Универсальный доступ | Бейджи и выбор окна приложения; подключается отдельно |

Без этих разрешений остальные функции доступны. Новые разрешения не
запрашиваются фоновым опросом. Сеть используется для обложек Spotify
и иконок сайтов, которые добавил пользователь; аналитики нет.
Подробности — [PRIVACY.md](docs/PRIVACY.md).

## Ограничения исходной базы

До 30 пространств, иконки 28–60 pt, два виджета; стопка показывает первые
500 нескрытых файлов папки. Музыка из браузера не поддерживается.
Определение рабочего стола использует необязательные символы SkyLight
и может перестать работать после обновления macOS.

Проверка на текущем Apple Silicon Mac не заменяет проверку на отдельной
машине с macOS 13, Intel или несколькими мониторами. Разрешения и реальные
источники данных не включаются автоматическими тестами.
